# Sushi Restaurant

A Flutter restaurant ordering app for browsing sushi items, managing a cart, checking out with Firestore-backed orders, and reviewing order history.

## Overview

This project is a mobile food ordering app built with Flutter and Firebase. Users can:

- browse sushi menu items
- view item details
- add items to cart
- clear cart with confirmation
- submit an order through a checkout modal
- view their own order history
- open order details
- confirm payment status updates
- sign in with email/password or Google

The app uses Firebase Authentication for login and Cloud Firestore for user profiles and orders.

## Firebase Data Model

### `users` collection

Each signed-in user stores a profile document under:

`users/{uid}`

Example fields:

- `uid`
- `email`
- `username`
- `provider`
- `createdAt`
- `lastLoginAt`
- `photoURL`

### `orders` collection

Each checkout creates a document in the top-level `orders` collection.

Example fields:

- `userId`
- `customerName`
- `customerEmail`
- `phoneNumber`
- `shippingAddress`
- `items`
- `paymentStatus`
- `totalAmount`
- `createdAt`
- `updatedAt`

Example `items` format:

```json
{
  "california_roll": 2,
  "spicy_tuna_roll": 1
}
```

## Firestore Rules

This app expects Firestore security rules that allow:

- authenticated users to read and write their own `users/{uid}` document
- authenticated users to create and read their own `orders`
- authenticated users to update their own order payment status

If these rules are not set, checkout and order loading will fail with a permission error.

## Setup

### Prerequisites

- Flutter SDK
- Dart SDK
- Firebase project
- Android Studio or VS Code
- An Android emulator, iOS simulator, or physical device

### Install Dependencies

```bash
flutter pub get
```

### Firebase Setup

This project uses Firebase configuration generated by FlutterFire CLI in:

- `lib/firebase_options.dart`

Make sure your Firebase project is configured for:

- Authentication
- Email/password sign-in
- Google sign-in
- Cloud Firestore

### Run the App

```bash
flutter run
```

## Notes

- Menu data is centralized in `lib/data/menu_catalog.dart` and uses stable product IDs for cart and order storage.
- Order payment is currently handled as an in-app status update in Firestore.
- The app uses reusable confirmation dialogs for actions like logout and clearing the cart.

## Assets
